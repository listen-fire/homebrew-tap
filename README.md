# Homebrew tap for listen-fire

```sh
brew install listen-fire/tap/listen-fire
```

`listen-fire` is the Listen-Fire command. The formula installs a prebuilt release from
[listen-fire/listen-fire](https://github.com/listen-fire/listen-fire) for macOS
(Apple silicon and Intel) and Linux (x64 and arm64), with Node for the built-in
modules. The formula is updated by the language repository's release workflow.

The formula was named `lf` before 0.12.13. `formula_renames.json` moves an
existing `lf` install to `listen-fire` on the next `brew upgrade`.
